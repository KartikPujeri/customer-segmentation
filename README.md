# 📊 Customer Segmentation & Purchase Analytics

A Machine Learning project that analyzes customer purchase data, segments customers based on their purchasing behavior using **K-Means Clustering**, and provides business insights through **Power BI** and an interactive web dashboard.

🌐 **Live Demo:** https://customer-segmentation-six.vercel.app/

---

## 🚀 Features

* Customer Segmentation using Machine Learning
* K-Means Clustering
* Customer Purchase Analysis
* Data Preprocessing & Feature Engineering
* Data Visualization
* Power BI Dashboard
* Business Insights
* Interactive Web Dashboard
* Customer Segment Analysis

## 🤖 Machine Learning

The project uses **K-Means Clustering** to group customers according to their purchasing behavior.

Customer-level features include:

* Total Purchase Amount
* Number of Purchases
* Average Purchase Value

The clustering process helps identify different customer segments based on their spending patterns and purchasing frequency.

---

## 📊 Dataset

The project uses two main datasets:

* **customer_transactions.csv** – Contains customer purchase and transaction information.
* **customer_segments.csv** – Contains the results of customer segmentation.

## ▶️ How to Run

### Clone the Repository

```bash
git clone https://github.com/KartikPujeri/customer-segmentation-purchase-analytics.git
```

### Go to the Project Folder

```bash
cd customer-segmentation-purchase-analytics
```

### Install Required Libraries

```bash
pip install pandas numpy matplotlib scikit-learn
```

### Generate Dataset

```bash
python programs/generate_data.py
```

### Perform Customer Segmentation

```bash
python programs/customer_segmentation.py
```

### Start the Dashboard

```bash
python programs/start_dashboard.py
```
